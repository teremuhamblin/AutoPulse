# 🧭 AutoPulse — ROADMAP Officielle
Moteur d’automatisme modulaire — Vision stratégique v1.0 → v2.0

---

# 🎯 Objectifs généraux
- Construire un moteur d’automatisme léger, modulaire, extensible.
- Offrir une API REST stable et cohérente.
- Fournir une WebUI cyber‑militaire simple, rapide, efficace.
- Préparer l’arrivée du scheduler temps réel et des alarmes.
- Stabiliser l’architecture pour la v2.0 (modules dynamiques).
